# MERIDIAN — a VAR(1) mechanism-stability diagnostic for grouping variables in fMRI

This repository accompanies the manuscript *"Site shifts regional autocorrelation,
condition shifts cross-region coupling: a vector-autoregressive diagnostic for
grouping variables in fMRI"*

**What the diagnostic does.** Given a grouping variable (scanning *site*, or
cognitive *condition*), it fits a first-order vector autoregression, VAR(1)
`x(t) = A x(t-1) + c + e(t)`, within each level of the grouping variable,
bootstraps subjects (100 resamples), and tests every coefficient of `A` for
stability across levels with a two-sample Wald z and Benjamini–Hochberg FDR
(q = 0.05). Where the instability lands is the readout: **diagonal** coefficients
are per-region autocorrelation (a measurement property, sensitive to TR/scanner);
**off-diagonal** coefficients are cross-region influence (directed effective
connectivity, i.e. mechanism). The finding is a double dissociation — across
ABIDE-I **sites** the instability is diagonal-only (0 of 2,450 off-diagonal
coefficients unstable), while across AOMIC rest-vs-working-memory **conditions** a
real off-diagonal shift is present — shown with the same machinery on both.

**No data is stored here** (see [`DATA.md`](DATA.md)). Committed content is code,
small result summaries, and the publication figures. All inputs are public.

## Reproducing every display item

Random seeds are fixed everywhere (`RNG_SEED = 20260628` for bootstraps;
matching fixed seeds for permutations and simulations), so every result below is
**deterministic** — re-running reproduces the reported numbers exactly.

Some intermediate per-coefficient CSVs are **gitignored** because they are large;
they are regenerated by the steps below and then consumed by the figure scripts.
Those files are flagged **(gitignored intermediate)**.

### 1. ABIDE-I site pipeline → Figures 2, 3, S1–S4

```bash
python scripts/build_dataset.py            # download + QC + ComBat-GAM  -> data/processed/abide_harmonized.npz
python scripts/test_a.py                   # Test A (site effect sizes)   -> results/test_a_results.csv
python scripts/test_b.py                   # VAR(1) bootstrap + Hotelling  -> results/test_b_results.csv, data/processed/test_b_bootstrap.npz
python scripts/test_b_marginal.py          # per-coefficient Wald + BH-FDR -> results/test_b_marginal.csv  (gitignored intermediate)
python scripts/annotate_unstable.py        # anatomical labels             -> results/test_b_unstable_coefficients.csv
python scripts/compute_panel_networks.py   # Yeo-7 labels per panel        -> results/panel_region_networks.csv
python scripts/make_paper_figures.py       # -> figures/paper/fig2_three_panel, figS1, figS2, figS3_abide_marginal_effects, figS4_condition_network_enrichment
python scripts/test_c_tr_instability.py    # TR–instability scatter        -> figures/paper/fig3_tr_vs_instability  (needs results/measured_tr.csv)
```

### 2. AOMIC condition pipeline → Figure 2 (panel C), Figure S4

```bash
python scripts/condition_sms/fetch_parcellate.py     # download + Schaefer-200 parcellate -> data/condition_sms/ts/
python scripts/condition_sms/test_condition_sms.py   # rest-vs-WM VAR(1) contrast -> results/condition_sms/marginal.csv  (gitignored intermediate)
python scripts/condition_sms/network_localize.py     # Yeo-7 enrichment + paired sensitivity test
# make_paper_figures.py (step 1) reads condition_sms/marginal.csv for Fig 2 panel C and figS4.
```

### 3. Simulation validation → Figure 4, Figure S5

```bash
python simulator/diagnostic_validation/run_validation.py       # CPU sweep -> .../results/all_cells.csv  (gitignored intermediate)
python simulator/diagnostic_validation/render_power_curve.py   # -> figures/paper/fig4_sim_power_curve
python simulator/diagnostic_validation/export_paper_figures.py # -> figures/unused/figS6_sim_null_fp_rate, figS7_sim_localization, figS8_sim_hrf_localization
python scripts/make_figS5_localization.py                      # merges the two localisation panels -> figures/paper/figS5_sim_localization_merged
```

## Notes

- **Determinism.** Every stochastic step (subject bootstraps, the TR permutation
  null, the simulation sweeps) uses a fixed seed (`RNG_SEED = 20260628` and
  matching constants). Reproductions are exact.
- **Scratch directories.** Scripts that need a temporary working directory use a
  per-run OS temp dir by default; set the `MERIDIAN_SCRATCH` environment variable
  to pin a fixed location.
- **Data.** Nothing under `data/` is committed; obtain the public inputs per
  [`DATA.md`](DATA.md).
